# libdvbs2

`libdvbs2` is a pure C library for DVB-S2 building blocks.

## Layout

- `include/dvbs2/` — installed public headers
- `src/` — library implementation (private headers stay here)
- `tests/` — unit and integration tests
- `examples/` — small, standalone usage programs
- `docs/` — design notes and API documentation

## Build

Requirements: a C99 compiler and GNU Make. GCC and Clang work on Linux and macOS;
on Windows, use a GNU-compatible toolchain such as MSYS2/MinGW or LLVM-MinGW.

```sh
make
make test
```

Use `make clean` to remove files generated by Make.

## Profiling

On Linux, `make profile` builds the benchmark with GNU `gprof` instrumentation,
runs it, generates `profile.txt` and `flamegraph.svg`, and opens the flamegraph
in Firefox. This target requires GNU `gprof`, Perl, Firefox, and the
`stackcollapse-gprof.pl` and `flamegraph.pl` scripts from the
[FlameGraph project](https://github.com/brendangregg/FlameGraph). By default,
Make looks for those scripts in `~/FlameGraph`; set `FLAMEGRAPH_DIR` if they are
installed elsewhere.
